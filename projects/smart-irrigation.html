Smart Soil Irrigation System

A Bluetooth-controlled smart irrigation robotic system designed to optimize water usage in agriculture using real-time soil and environmental data.

Core Features

  • Automated irrigation using soil moisture thresholds
  • Temperature and humidity monitoring via DHT11
  • Manual control using Bluetooth (HC-06)
  • Mobile robotic platform for field navigation

Hardware Used

Arduino UNO · Soil Moisture Sensor · DHT11 · HC-06 · L298N · Water Pump

The system activates irrigation only when moisture levels fall below a defined threshold, preventing overwatering and conserving resources.
