Foreign Object Debris Detection

A computer vision-based system for detecting and classifying foreign object debris on airfield runways using deep learning and embedded hardware.

Approach

  • YOLOv8 Nano model for object detection
  • Custom dataset with 4000+ annotated images
  • Real-time image streaming via ESP32-CAM

Technologies

Python · YOLOv8 · OpenCV · ESP32-CAM · Edge AI

The system achieved high detection accuracy while maintaining low computational cost, making it suitable for scalable deployment.
