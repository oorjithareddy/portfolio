Autonomous Warehouse Robot Controller

This project implements and compares two real-time scheduling algorithms — Rate Monotonic Scheduling (RMS) and Earliest Deadline First (EDF) — on the STM32F446RE microcontroller.

The system simulates an autonomous warehouse robot where periodic tasks represent motion control, path planning, telemetry, and diagnostics.

Key Focus

  • Real-time scheduling on embedded systems
  • Deadline adherence and CPU utilization
  • Runtime switching between RMS and EDF
